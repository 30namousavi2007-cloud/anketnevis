# بک‌اند آنکت‌نویس

بک‌اند Express + PostgreSQL برای سایت آنکت‌نویس. در این مرحله فقط سیستم احراز هویت (ثبت‌نام/ورود واقعی) پیاده شده؛ در قدم‌های بعدی مدیریت کتاب‌ها/مقالات، نظرات، و آپلود فایل اضافه می‌شن.

## پیش‌نیاز: ساخت دیتابیس رایگان PostgreSQL

این بک‌اند با هر سرویس PostgreSQL کار می‌کند. پیشنهاد ما **Supabase** است (پلن رایگان دائمی + فضای ذخیره‌سازی فایل برای مراحل بعدی پروژه).

### گزینه‌ی پیشنهادی: Supabase

1. به [supabase.com](https://supabase.com) بروید و با گیت‌هاب یا ایمیل ثبت‌نام کنید.
2. روی **New project** بزنید، نام پروژه را `anketnevis` بگذارید.
3. یک **رمز عبور دیتابیس** می‌خواهد؛ رمز قوی بسازید و آن را جایی ذخیره کنید.
4. یکی دو دقیقه صبر کنید تا پروژه ساخته شود.
5. روی دکمه‌ی **Connect** (یا Settings ← Database) بزنید، تب **Connection string** و حالت **URI** را انتخاب کنید.
6. در رشته‌ی کپی‌شده، عبارت `[YOUR-PASSWORD]` را با رمزی که در مرحله‌ی ۳ ساختید جایگزین کنید.

### گزینه‌های دیگر

- **Neon** ([neon.tech](https://neon.tech)) — سرورلس، پلن رایگان دائمی
- **Railway** ([railway.app](https://railway.app)) — اعتبار ماهانه‌ی محدود رایگان

در هر صورت فقط کافی است رشته‌ی اتصال (که با `postgresql://` شروع می‌شود) را در `DATABASE_URL` بگذارید؛ نیازی به تغییر کد نیست.

## راه‌اندازی محلی

```bash
cd backend
npm install
cp .env.example .env
```

فایل `.env` رو باز کنید و این دو مقدار رو پر کنید:
- `DATABASE_URL` = همون connection string که از Supabase (یا سرویس دیگر) کپی کردید
- `JWT_SECRET` = یک رشته‌ی تصادفی و بلند (مثلاً با اجرای `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` بسازیدش)

سپس ساختار جدول‌ها رو روی دیتابیس اعمال کنید:

```bash
npm run migrate
```

اگه پیام «✅ ساختار دیتابیس با موفقیت اعمال شد» رو دیدید، یعنی جدول `users` ساخته شده.

در نهایت سرور رو اجرا کنید:

```bash
npm run dev
```

سرور روی `http://localhost:4000` بالا میاد. برای تست سلامت سرور، این آدرس رو توی مرورگر باز کنید:
`http://localhost:4000/api/health`

## نکته‌ی مهم درباره‌ی فرانت‌اند

فرانت‌اند (`App.jsx`) به‌صورت پیش‌فرض به `http://localhost:4000` وصل می‌شه. یعنی برای این‌که ثبت‌نام/ورود کار کنه، باید **هم بک‌اند و هم فرانت‌اند همزمان اجرا باشن** (دو ترمینال جدا).

## مسیرهای API فعلی

| متد | مسیر | توضیح |
|---|---|---|
| POST | `/api/auth/register` | ثبت‌نام با نام، ایمیل، رمز عبور |
| POST | `/api/auth/login` | ورود با ایمیل و رمز عبور |
| GET | `/api/auth/me` | دریافت اطلاعات کاربر لاگین‌شده (نیاز به هدر `Authorization: Bearer <token>`) |
| GET | `/api/health` | بررسی سلامت سرور |
